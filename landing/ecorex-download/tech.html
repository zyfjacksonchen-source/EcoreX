技术说明

EcoreX Agent
技术架构

EcoreX 是面向广告业务的 Electron + React 桌面 Agent。它把对话、项目文件、联网检索、 MCP、Skill、本地执行和安全确认组织成一个可恢复、可隔离、可审计的工作流。

系统分层

前端负责体验，主进程负责边界，本地执行层负责闭环。

01

React 交互层

使用 React 构建桌面对话、项目管理、文件引用、富文本产物、权限弹窗、设置页和预览面板。页面状态围绕会话、项目、任务树和产物卡片组织，支持多会话并行运行时的前台切换。

02

Electron 主进程

主进程承接窗口、IPC、文件系统、系统打开、会话恢复、账号权限、模型配置、MCP/Skill 管理和安全策略。渲染层只通过受控 API 请求能力，避免直接越权访问本机资源。

03

本地执行引擎

执行层按任务目标调度搜索、文件读写、终端命令、文档生成、图片生成和外部能力调用。它负责把模型输出转成可执行步骤，并把中间状态同步回会话时间线。

04

数据与产物层

项目资料、会话历史、任务状态和生成产物按作用域持久化。项目会话只检索当前项目文件，通用会话不混入项目私有资料，关闭或重启后仍可继续查看历史和已生成文件。

Agent LOOP

每个任务都按观察、规划、执行、校验、沉淀循环推进。

  1. Observe读取用户目标、项目上下文、可用文件、权限模式和已配置能力。
  2. Plan拆解任务树，决定是否需要联网检索、MCP、Skill、终端或文档工具。
  3. Act串行或并发调用工具，生成中间结果，并把关键进度回写到会话。
  4. Verify检查文件是否存在、格式是否可打开、预览是否可读、任务状态是否完成。
  5. Persist保存会话、产物、项目索引和可恢复状态，支持切换会话或重启后续跑。

能力扩展

MCP 与 Skill 只从 EcoreX 托管范围内启用。

MCP 接入

系统设置页展示真实 MCP 状态、启用状态、错误和连接信息。任务运行时按能力匹配优先调用，例如表格类任务优先走 Excel MCP，避免只生成普通文件而不调用专业工具。

Skill 路由

Skill 用于封装高阶业务流程，例如 PPT 生成、广告复盘、项目资料整理等。EcoreX 会屏蔽本机个人编程插件类能力，只加载内置能力和在 Skill 管理中明确出现的托管能力。

模型与多模态

模型配置与执行适配在主进程集中管理。文本、联网、文档和图片生成使用不同能力路径，图片生成默认走图像模型能力，并将生成图片直接回填到聊天富文本和产物区。

安全护栏

所有本地能力都围绕最小权限、可见确认和路径边界设计。

权限模式默认权限、完全访问等模式由用户显式选择，高风险动作通过弹窗确认。
路径边界项目文件、产物、中间文件和系统目录按作用域校验，避免跨项目污染。
命令治理命令执行会过滤无关或危险参数，并把用户无关的底层噪声从对话中清理。
账号角色本地账号、管理员角色、设置权限和能力管理权限分离，降低误操作风险。
会话恢复任务中断、关闭应用或切换会话后，已生成产物保留，任务可在原会话恢复。
发布清理打包时排除日志、密钥、测试会话、个人能力包和本地脏文件，保证安装包干净。

文件与项目

项目是记忆、文件、会话和产物的隔离边界。

项目管理支持上传项目资料、维护长期记忆、查看资源树，并在项目对话中通过 @ 引用文件。文档、表格、演示文稿、PDF、HTML、文本和图片会生成产物卡片，优先在 EcoreX 内预览，必要时调用系统方式打开。

通用对话不主动查询项目文件；项目对话只检索当前项目的主动上传文件和已生成产物。中间产物、记忆文件和运行缓存不会作为用户可选项目资料展示。

交付验证

上线前覆盖构建、生产校验、打包输入和发布洁净度。

Windows 与 macOS 使用 Electron Builder 产出安装包；发布流程会执行构建、生产检查、原生依赖检查、文档预览依赖检查和安装包洁净度检查，确保用户开箱即用。
