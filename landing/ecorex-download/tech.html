技术说明

EcoreX Agent
技术架构

面向广告业务的桌面 Agent，把对话、项目文件、联网检索、MCP、Skill、本地执行与安全确认组织成可恢复、可隔离、可审计的工作流。

Electron React Agent LOOP MCP / Skill

系统分层

前端负责体验，主进程负责边界，本地执行层负责闭环。

01React 交互层

承载对话、项目管理、文件引用、富文本产物、权限弹窗、设置页和预览面板。

02Electron 主进程

管理窗口、IPC、文件系统、系统打开、账号角色、模型配置、MCP 与 Skill 状态。

03本地执行引擎

把模型计划转成文件、终端、联网、文档、图片和外部能力调用。

04数据与产物层

按作用域保存项目资料、会话历史、任务状态和可再次打开的生成产物。

Agent LOOP

每个任务沿着观察、规划、执行、校验、沉淀循环推进。

  1. Observe读取用户目标、项目上下文、可用文件、权限模式和已配置能力。
  2. Plan拆解任务树，选择联网检索、MCP、Skill、终端或文档工具。
  3. Act串行或并发执行工具，把关键进度持续回写到会话。
  4. Verify检查文件、格式、预览、任务状态和用户可见结果。
  5. Persist保存会话、产物、项目索引和恢复点，支持切换会话后续跑。

能力扩展

MCP 与 Skill 只从 EcoreX 托管范围内启用。

MCP 接入

设置页展示真实连接、启用、授权与错误状态。表格类任务优先走 Excel MCP，避免只生成普通文件。

Skill 路由

封装 PPT、广告复盘、资料整理等高阶流程，并屏蔽本机个人编程插件类能力。

多模态模型

文本、联网、文档和图片生成分别走适配后的能力路径，图片直接进入聊天富文本与产物区。

安全护栏

本地能力围绕最小权限、可见确认和路径边界设计。

权限模式默认权限、完全访问等模式由用户显式选择，高风险动作弹窗确认。
路径边界项目文件、产物、中间文件和系统目录按作用域校验。
命令治理过滤无关或危险参数，清理用户无关的底层噪声。
账号角色本地账号、管理员角色、设置权限和能力管理权限分离。
会话恢复任务中断或重启后，已生成产物保留并可在原会话恢复。
发布清理排除日志、密钥、测试会话、个人能力包和本地脏文件。

文件与项目

项目是记忆、文件、会话和产物的隔离边界。

项目资料

上传资料、长期记忆和生成产物进入项目资源树，并可在项目对话中通过 @ 引用。

通用对话

通用会话不主动查询项目私有文件，避免测试项目资料混入公共历史。

产物预览

文档、表格、演示文稿、PDF、HTML、文本和图片生成产物卡片，优先在 EcoreX 内预览。

交付验证

上线前覆盖构建、生产校验、打包输入和发布洁净度。

Windows 与 macOS 使用 Electron Builder 产出安装包；发布流程执行构建、生产检查、原生依赖检查、文档预览依赖检查和安装包洁净度检查。
