How to install

Windows / macOS 安装指南

首次安装

  1. 选择对应系统Windows 用户选择 Windows x64；Mac 用户按芯片选择 Apple Silicon 或 Intel。
  2. 下载并打开终端会持续显示当前阶段、百分比、实时速度和预计剩余时间，并自动完成校验与安装。
  3. 开始使用安装完成后会自动打开浏览器中的 EcoreX；以后也可以从本机入口再次打开。

关闭后重新打开

  1. 使用本机入口打开 EcoreX 入口会先恢复本地服务，再进入浏览器中的工作区。
  2. 页面地址保持不变项目、会话和产物仍保存在本机，不会因为关闭页面而丢失。
  3. 入口异常时重新安装重新运行同平台 Bootstrap 会修复本地入口，并保留已有用户数据。

以后更新

  1. 后台自动下载EcoreX 检测到新版本后在后台下载，不打断当前任务。
  2. 由你确认激活准备完成后点击“更新并刷新”，才会切换到新版本。
  3. 失败自动回退新版本健康检查失败时自动恢复上一个可用版本。
