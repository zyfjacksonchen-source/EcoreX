How to install

Windows / macOS 安装指南

首次安装

  1. 下载选择与你的 Windows 或 Mac 电脑匹配的版本。
  2. 解压下载完成后，打开压缩包并解压到本机。
  3. 双击 EcoreX Installer它就在解压后的第一层；安装完成后会自动打开 EcoreX，并在桌面创建快捷方式。

关闭后重新打开

  1. 双击桌面 EcoreX关闭网页后，随时可以通过桌面快捷方式重新打开。
  2. 页面地址保持不变项目、会话和产物仍保存在本机，不会因为关闭页面而丢失。
  3. 打不开时重新安装再次运行同一安装程序即可修复桌面快捷方式，并保留已有用户数据。

以后更新

  1. 后台自动下载EcoreX 检测到新版本后在后台下载，不打断当前任务。
  2. 由你确认激活准备完成后点击“更新并刷新”，才会切换到新版本。
  3. 失败自动回退新版本健康检查失败时自动恢复上一个可用版本。
