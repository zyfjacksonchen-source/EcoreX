How to install

Windows / macOS 安装指南

首次安装

  1. Windows：打开 PowerShell 在开始菜单搜索 PowerShell，普通打开即可；不需要提前安装 npm 或下载安装包。
  2. Windows：粘贴命令并回车 powershell -ExecutionPolicy Bypass -NoProfile -Command "iwr https://www.ecoreai.cn/ecorex-agent/install-webui.ps1 -UseB | iex"
  3. macOS：打开终端 按 Command + Space 打开聚焦搜索，输入“终端”或 “Terminal”，回车打开。
  4. macOS：粘贴命令并回车 curl -fsSL https://www.ecoreai.cn/ecorex-agent/install-webui.sh | bash
  5. 等待自动完成 脚本会读取 manifest、下载对应系统的 WebUI 包、校验 SHA256、安装本地运行时，并自动打开浏览器里的 EcoreX。

关闭后重新打开

  1. 优先双击桌面入口 安装完成后桌面会生成 EcoreX WebUI.url，双击即可重新打开浏览器入口。
  2. macOS 双击桌面入口 macOS 安装完成后桌面会生成 EcoreX WebUI.webloc，双击即可重新打开浏览器入口。
  3. 入口打不开时重跑安装命令 如果本地服务已被关掉或端口变化，重新执行同一条安装命令会拉起服务并打开 EcoreX。

以后更新

  1. 仍然运行同一条命令 安装脚本每次都会重新读取线上 manifest，下载最新 WebUI 包并校验 SHA256 后再替换。
  2. 下载中断直接重跑 如果出现 Recv failure、Operation timed out 或网络中断，重新执行同一条命令即可继续重试下载。
  3. 项目和会话保留在本机 更新网页端不会清空项目列表；本机工作区、项目文件夹和 .ecorex/ui-state.json 会继续沿用。
