How to install

Windows / macOS 安装指南

首次安装

  1. 选择系统Windows 选择 Windows x64。Mac 按芯片选择 Apple Silicon 或 Intel。
  2. 复制安装命令点击对应卡片中的“复制命令”。
  3. 粘贴并执行Windows 在 PowerShell、Mac 在终端中粘贴执行；命令会从国内 GitHub 镜像下载。安装完成后自动打开 e-Mate 并创建桌面快捷方式。不需要预装 npm。

关闭后重新打开

  1. 双击桌面 e-Mate关闭网页后，随时可以通过桌面快捷方式重新打开。
  2. 页面地址保持不变项目、会话和产物仍保存在本机，不会因为关闭页面而丢失。
  3. 打不开时重新执行命令再次执行同一系统的安装命令即可修复桌面快捷方式，并保留已有用户数据。

以后更新

  1. 后台自动下载e-Mate 检测到新版本后在后台下载，不打断当前任务。
  2. 由你确认激活准备完成后点击“更新并刷新”，才会切换到新版本。
  3. 失败自动回退新版本健康检查失败时自动恢复上一个可用版本。
