桌面端下载 WebUI

浏览器入口

e-Mate WebUI

与桌面端使用同一个本机 Runtime，任务、会话、工具和文件都来自同一份本机数据；无需安装第二套运行环境。
01

安装桌面端

如果还没有安装，请先从官方下载页选择这台电脑的版本。

02

启动 Runtime

先打开 e-Mate 桌面端，等待本机连接就绪。

03

浏览器打开

在 e-Mate 应用菜单中选择“在浏览器中打开 WebUI”。桌面窗口和浏览器可以同时使用。

一行命令打开

使用默认本机端口

桌面端已连接且使用默认端口时，也可以复制命令直接打开；应用菜单会始终使用当前实际端口。

macOS

在“终端”运行：

open "http://127.0.0.1:8765/"

Windows

在 PowerShell 运行：

Start-Process "http://127.0.0.1:8765/"

独立 WebUI

一行安装并启动

沿用桌面端的同一个 Runtime、会话和 ~/.emate 用户数据；已安装桌面端时不会创建第二套状态。

macOS

在“终端”运行：

curl -fsSL https://dl.ecoremedia.net/e-mate/update/install-webui.sh | sh

Windows x64

在 PowerShell 运行：

irm https://dl.ecoremedia.net/e-mate/update/install-webui.ps1 | iex

同一份工作状态

桌面端与 WebUI 共存

同一个 Agent

WebUI 不会启动第二套 Agent，也不会复制任务、会话或工具状态。

同一份本机数据

桌面端与浏览器访问的是同一个 Runtime 和同一用户数据目录。

独立窗口

关闭浏览器页面不会停止桌面端 Runtime；需要时可再次从应用菜单打开。
