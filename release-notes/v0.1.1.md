# EcoreX v0.1.1

EcoreX v0.1.1 is the enterprise desktop build for advertising agencies. It keeps the existing agent runtime while introducing enterprise login, administrator governance, unified provider/API key setup, daily token limits, audit history, and an orange-led light/dark visual system.

## Highlights

- Rebranded the desktop and web UI to EcoreX with user-facing legacy product strings removed.
- Added enterprise authentication with the default administrator `admin@ecorex.local`; first login requires changing the default password.
- Added an administrator page for user lifecycle, roles, daily token limits, token usage, audit logs, provider setup, and version policy.
- Moved provider/API key configuration behind administrator-only APIs and frontend controls.
- Added daily token accounting and quota blocking for member users.
- Collapsed appearance to EcoreX Light and EcoreX Dark.

## Verification Focus

- Enterprise login and forced password-change flow.
- Administrator user, quota, provider, audit, and version policy controls.
- Member provider self-service lockout.
- Desktop production build and native package smoke on supported hosts.
