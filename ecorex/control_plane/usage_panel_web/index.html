EcoreX Agent 使用情况

RAW 表
产物有效性 用户勾选 👎 的产物定义为无效；未被标记无效且状态可用的产物计入有效产物。
任务状态 任务分为成功、失败、中止；中止表示用户主动停止任务，不再混入失败。
使用场景 创作内容=创作文案/标题/报告/脚本等；制作素材=制作图片、海报图片编辑等；搜索查询=网页搜索抓取等；处理数据=数据处理（Excel/word/ppt/pdf）等；编辑文档=操作在线文档（飞书/腾讯文档）等；交付通知=打包/展示/发消息/提醒等；系统维护=环境检查/排错/配置等。
任务 用户发起一次需求并被系统接收，就算 1 次使用 事件 后台记录的一条动作，比如接收、完成、取消、工具执行、产物更新
任务状态说明： 成功 = 当天有成功完成的任务 失败 = 已接收但未成功且非用户主动停止 中止 = 用户主动停止任务
