# EcoreX v0.3.1 开发执行切片

## 执行原则

- 本文档是 v0.3.1 实施顺序的唯一依据；需求变更先更新本文档再改代码。
- 每个切片必须同时满足：代码完成、最小相关测试通过、`development-log.md` 已记录。
- 保留实施前已存在的用户改动，特别是构建/冒烟脚本及 macOS WebUI 生产者测试。
- 优先复用现有能力注册表、连接器目录、Radix 菜单、原生目录选择器和不可变 ClientOperation。
- 产品边界与前几版一致：只交付可稳定运行的 e-Mate WebUI，同一 WebUI 链路覆盖 Windows/macOS；不开发 Electron、Tauri、SwiftUI、WinUI 等独立桌面客户端。
- CowAgent 上游更新只按 EcoreX 现有架构移植可验证行为，不复制其桌面壳或平行实现；对照基线为官方仓库 `866d40c5`、发布说明 `2.1.3`—`2.1.5`。

## 切片顺序

### S0 基线与契约

- 盘点工作树和现有测试，不覆盖用户改动。
- 固定前端类型/契约、Python 任务目录、模型目录与项目选择器基线。
- 退出条件：基线命令及已知失败全部记录。

### S1 首页与聊天框

- 修复首页固定高度+居中导致的顶部裁切，短高度时从顶部正常滚动。
- 模板预填为一次性事件，Composer 重挂载不再重复注入。
- 最近任务使用现有 `openThread` 导航。
- 首页项目选择复用已有 Radix 项目菜单，常显“添加项目文件夹…”。
- 退出条件：AC-01、AC-09、AC-11、AC-14 通过。

### S2 基础 UI 收敛

- 完全访问使用 `role=switch`，开启仍需二次确认，关闭立即回到默认权限。
- 密码表单改为当前密码独立行、新密码/确认密码自适应双列。
- 任务行去掉普通消息图标和列表底部黑框，保留固定/运行状态。
- 能力分类由原生下拉改为带现有 Lucide 图标的常显筛选项。
- 退出条件：AC-02、AC-04、AC-06、AC-07 通过。

### S3 协作连接

- 删除 Composer 连接器按钮和延迟加载路径。
- 能力中心“协作连接”展示飞书、腾讯文档与现有外部 IM，复用已有登录/检查/重连/断开后端。
- 未配置的管理员凭据型连接只显示明确原因，不伪造可用开关。
- 退出条件：AC-03 通过。

### S4 自建 Skill

- 主流程只要 ZIP，后端从 `SKILL.md` 名称生成稳定 extension ID。
- 旧 `extension_id` 字段保留为可选兼容输入；冲突、非法包和不安全路径仍失败关闭。
- Hub 发布收进“高级操作”，不挤占日常安装流程。
- 退出条件：AC-05 通过。

### S5 `@`能力精准调用

- 菜单来源为当前快照中已启用且就绪的系统工具、Skill 和协作能力。
- 支持输入搜索、上下键、Enter、Escape、点击与删除标签。
- 稳定 ID 进入 ClientOperation 指纹与 outbox，create/steer/queue/replace/retry 保持同一选择。
- 纯文本 `@`不产生授权；后端仍执行权限、可用性和快照校验。
- 退出条件：AC-13 通过。

### S6 归档任务生命周期

- 归档行可打开，时间线只读，隐藏 Composer 并提供恢复。
- 删除仅允许作用于 archived，写入 `deleted` 状态和审计事件，该状态不出现于 active/archived/all 用户列表。
- 恢复/删除保持幂等，不物理删除事件、轮次或产物记录。
- 退出条件：AC-12 通过。

### S7 双端原生资源管理

- 项目目录、输出目录、打开文件、定位文件统一经过现有平台适配层。
- Windows 所有子进程使用 `CREATE_NO_WINDOW`、`DEVNULL` 与 `shell=False`；macOS 使用 Finder/`open` 固定命令。
- 退出条件：AC-08 通过。

### S8 工具返回准确性与运行稳定性

- 统一外部命令退出码语义：`grep`/`rg` 无匹配与 `find` 部分目录不可访问不再误报为工具崩溃，仍保留真实 stderr 和非预期退出码。
- 浏览器脚本兼容表达式与函数体两种执行方式，不再把可执行函数体误报为语法错误。
- 图片读取统一通过工作区路径解析器解析相对路径，并继续拒绝越界路径。
- Web 流连接在客户端断开、取消和生成器结束时回收；自主进化受限工具集不得被 MCP 注册流程重新注入。
- 退出条件：AC-15、AC-19 通过。

### S9 远程 MCP OAuth

- 在现有远程 HTTP MCP transport 上增加标准 OAuth 授权发现、PKCE、state 校验、浏览器授权回调、令牌刷新与撤销/清除。
- OAuth 状态按租户和 MCP 服务隔离；令牌走现有 secret store，不进入日志、前端目录快照或明文配置。
- 无 OAuth 的本地 stdio/远程 MCP 行为保持兼容；授权失败可重试但不得产生无限登录循环。
- 退出条件：AC-16 通过。

### S10 飞书通道增强

- 流式卡片使用可折叠执行面板展示思考摘要、工具调用和耗时；敏感工具参数继续脱敏。
- 非流式回复与定时推送含 Markdown 时渲染卡片；`/tasks` 返回可启停的任务卡片并走现有调度命令。
- 引用消息内容进入本次 Agent 上下文；远程图片下载校验后上传/渲染到飞书卡片。
- 飞书撤回事件按消息—请求关联取消对应运行中或排队任务，重复事件保持幂等。
- 退出条件：AC-17 通过。

### S11 模型策略与热更新

- 端到端推理强度合同增加 `max`。
- `gpt-5.6-luna` 为默认且 `max`；DeepSeek 显示/上游更新为 V4 Flash 且 `max`，保留本地稳定 ID 兼容性。
- 管理员目录驱动展示名、上游模型、默认项和推理强度；前端复用心跳+窗口聚焦刷新。
- 新轮次使用新快照，运行中轮次保持冻结；已选模型被移除时回退到新默认。
- 退出条件：AC-10 通过。

### S12 内置运行环境、版本与发布验证

- 先生成 Windows/macOS 包内容与体积清单；若已内置运行环境，则在保持自包含的前提下减包，不重复打入解释器、依赖或资源。
- Windows/macOS WebUI 分发包只保留运行所需的 Python、Node/工具二进制和飞书依赖，排除缓存、测试、开发头文件、静态库、源码映射及未引用依赖，干净机器安装后无需另装 Python。
- 建立分平台总包、runtime 子目录和 Top-N 文件体积回归门禁；任何增长必须有清单差异与运行必要性证据。
- 将用户可见与发布合同中的当前版本升级为 `0.3.1`，不改历史迁移文件中的旧版本字面量。
- 通过类型、契约、单元、Python、Playwright、构建与双端冒烟门禁。
- 按截图参考与相同视口完成视觉 QA，证据写入验收文档。
- macOS 最终构建使用当前账号仓库的最新 workflow；发布由手动 workflow/release 步骤触发，不开启自动发布。
- GitHub CLI 上传前只读发现当前 UniClash 代理地址，仅为当次 `gh` 进程设置 `HTTP_PROXY`/`HTTPS_PROXY`，不改系统代理。
- 下载页页眉只保留 e-Mate 图形标志，不再显示橙色 `e-Mate` 小字；五个机器人始终同屏，滑动/点击切换首位机器人及对应的用户语言能力说明，移除安装命令与更新策略技术文案。
- 下载发现必须与产品 SemVer/单调序列合同共用 `major*100000000 + minor*10000 + patch + 1`，接受 `0.3.1`；页眉显示纯版本号，安装命令由 npm 调用并优先使用公开指针下发的国内 GitHub 镜像。
- 退出条件：AC-01—AC-20 全部勾选，无 P0/P1/P2 视觉问题，公网下载页和 0.3.1 指针读回一致。
