## 功能验收

### AC-01 首页不裁切

- [ ] 641×249、1366×768、1920×1080 视口下，机器人、主标题、Composer 可通过正常滚动完整查看。
- [x] 内容高度不足时仍保持居中视觉，不出现双重滚动条。
- 证据：`artifacts/ac-01-*.png`。

### AC-02 权限切换

- [x] 设置中权限控件对读屏软件暴露 `switch` 和正确 checked 状态。
- [x] 默认→完全访问必须确认；取消不变更；完全访问→默认立即生效。
- [x] 请求失败时开关回到服务端真实状态并显示错误。

### AC-03 协作连接

- [x] Composer 无“连接器”按钮。
- [x] 协作连接页至少展示飞书、腾讯文档与后端已注册的外部 IM，图标/名称/健康状态与目录一致。
- [x] OAuth 登录、检查、重连、断开调用现有后端；管理员凭据未配置时不能误导为已连接。

### AC-04 能力分类

- [x] 全部、系统、办公、图像/媒体、协作、数据、开发、自动化、通用分类常显且都有图标。
- [x] 鼠标、键盘和触摸都可切换，筛选数量与列表一致。

### AC-05 自建 Skill

- [x] 用户无需输入 extension ID，选择合法 ZIP 即可安装。
- [x] 自动 ID 稳定，同包重试幂等；非法 frontmatter、超限和路径穿越继续被拒绝。
- [x] Hub 发布默认折叠，展开后保留原有发布能力。

### AC-06 任务列表视觉

- [x] 普通任务行左侧无消息框图标，固定和运行状态仍可识别。
- [x] 任务列表底部无独立黑色框/卡片接缝，滚动到底时不闪烁。

### AC-07 密码表单

- [x] 宽屏当前密码占整行，新密码/确认密码两列；窄屏三项单列。
- [x] 标签、输入框、错误和提交按钮不重叠不截断。

### AC-08 双端资源管理

- [x] Windows 项目/输出目录选择直接弹出原生窗口，无 PowerShell/cmd 窗口。
- [ ] Windows 打开/定位产物无终端窗口；macOS 对应流程使用 Finder。
- [x] 取消选择不改变现有项目/输出目录。

### AC-09 最近任务

- [x] 最近任务标题是可聚焦按钮，点击/Enter 进入正确 thread。
- [x] 进入后首页/创意中心关闭，移动端侧边栏关闭。

### AC-10 模型策略与热更新

- [x] 新安装默认选择 GPT-5.6 Luna，reasoning effort=`max`。
- [x] DeepSeek 显示 V4 Flash，上游请求为 V4 Flash，effort=`max`。
- [x] 管理员新增/修改/下线模型后，打开选择器前或 5 秒心跳内可见，无需重启客户端。
- [x] 下线当前已选模型后回退到服务端新默认；运行中任务快照不被改写。

### AC-11 模板预填

- [x] 选择“灵感探索”后只预填一次；发送、切换首页/任务、Composer 重挂载都不会再出现。
- [x] 用户已有草稿时模板不覆盖。

### AC-12 归档查看/恢复/删除

- [x] 归档项可打开完整时间线，界面明确只读且无法发送。
- [x] 恢复后返回 active 列表并可继续对话。
- [x] 删除需确认，仅 archived 可删；删除后 active/archived/all 均不返回。
- [x] 数据库仍保留 thread 与事件，存在唯一 `thread.deleted` 审计事件；重试不产生重复事件。

### AC-13 `@`能力

- [x] 输入 `@` 显示已启用且就绪的系统能力、Skill 和协作能力，可搜索和键盘选择。
- [x] 选中项显示标签并可删除；发送成功清空，发送失败保留。
- [x] create/steer/queue/replace 和离线 outbox 重试的 `explicit_tool_ids` 与指纹一致。
- [x] 未经菜单选择的普通 `@name` 不进入结构化授权；已停用/不可用能力不出现或被后端拒绝。

### AC-14 项目菜单

- [x] 聊天框下方使用主题化 Radix 菜单，不出现系统灰色原生 select 弹层。
- [x] 项目列表与“添加项目文件夹…”同时可见，菜单层级高于首页概览。
- [x] 添加成功后自动选中新项目，取消不变更选择。

### AC-15 工具返回准确性

- [x] `grep`/`rg` 无匹配退出码 1 返回“无匹配”而非失败；真正的参数/执行错误仍失败并保留诊断。
- [x] `find` 有结果但部分目录不可访问时返回结果与警告，不触发无意义重试；完全不可执行仍失败。
- [x] 浏览器脚本表达式和函数体都能执行，真实语法错误仍准确报告。
- [x] 工作区内相对图片路径可解析，绝对路径兼容，`..` 越界与非允许 URL 继续被拒绝。

### AC-16 远程 MCP OAuth

- [x] 需要登录的远程 MCP 可完成授权发现、PKCE 登录和回调，state/redirect 校验失败时拒绝交换令牌。
- [x] access token 过期可刷新；授权取消、刷新失败和服务下线有明确可恢复状态，不无限弹登录。
- [x] OAuth 状态与令牌按租户/服务隔离并使用现有 secret store；日志、接口响应和 WebUI 不泄露令牌。
- [x] 无 OAuth 的 HTTP MCP 与 stdio MCP 回归通过。

### AC-17 飞书通道增强

- [x] 流式卡片折叠面板展示思考摘要、工具调用和总耗时，最终态与中断态均可收口。
- [x] 非流式/定时回复含 Markdown 时使用卡片；纯文本仍走轻量文本路径。
- [x] `/tasks` 卡片可启用/停用任务，重复点击幂等且状态与调度后端一致。
- [x] 引用消息内容进入对应请求上下文；远程图片通过大小、类型和 SSRF 校验后显示。
- [x] 撤回消息取消其对应运行中或排队请求，重复/无关联撤回不影响其他任务。

### AC-18 开箱即用运行环境

- [ ] Windows/macOS WebUI 安装包在无系统 Python/Node 的干净环境可启动并通过 runtime self-check。
- [ ] 浏览器、文件搜索和飞书所需运行依赖均来自包内或受控的按需资源，不弹终端、不要求用户执行安装命令。
- [x] 缺少可选能力时只降级该能力并给出可操作状态，不拖垮 Web 服务。
- [x] 两个平台都有可复现的包内容/体积清单，解释器、依赖和前端资源不存在重复副本。
- [x] 缓存、测试、开发头文件、静态库、源码映射和未引用包不进入发布物；减包前后 self-check、主流程和飞书/浏览器/文件搜索冒烟一致通过。
- [x] 总包与 runtime 子目录体积门禁生效；超预算构建失败并打印 Top-N 增长来源。

### AC-19 Web 与自主进化稳定性

- [x] SSE/流式请求正常结束、用户取消和客户端断开后都释放生成器、订阅和文件描述符；重复连接压力测试无持续增长。
- [x] 自主进化审查运行时即使刷新 MCP 目录，也不能重新获得被策略移除的写入/外部工具。
- [x] 清理与限制路径有定向回归测试，服务关闭不遗留后台任务。
