- Run target deploy smoke and rollback smoke against the target release environment.

## Notes

- `scripts/smoke-web-runtime-real-network-browser.py` is a reviewed local HTTP/SSE browser smoke: it serves real `chat.html` plus localhost JSON/SSE endpoints, uses the browser's real fetch/EventSource path, proves stable terminal projection, proves exact reconnect exhaustion with `last_event_id`, and proves `stream_lost` backend projection recovery without `/api/history` fallback.
- That reviewed local HTTP/SSE coverage closes the previous broader reconnect-network risk for this release gate. It is not public-network or external-service validation.
- `scripts/smoke-v022-release-deploy-rollback.py` is a reviewed local filesystem smoke for the v0.2.2 Web Linux service tarball. It verifies package integrity and rollback mechanics before target execution.
- `scripts/smoke-v022-release-target-deploy-rollback.py` is the target-environment wrapper. It uploads the reviewed package and release scripts over SSH/scp, installs v0.2.2, runs the target checker, restores the previous `current` pointer, restarts the service, and stores only hashed/redacted command, host, URL, stdout, and stderr evidence.
- Its `--print-command-template` mode is only an operator handoff aid: it emits `READY_FOR_TARGET_INPUT` when local artifacts are ready, writes a gate-validated handoff template artifact, and does not execute the target smoke.
- `scripts/audit-v022-goal-completion.py` is a completion-audit view over existing evidence. It reports `PASS` only when the release gate is releasable and every objective requirement is proven.
- `scripts/smoke-feishu-im-real-credential.py` is a reviewed real Feishu/IM credential smoke for read-only authorization and chat-list reachability. It intentionally omits raw user ids, chat ids, names, tokens, and full chat payloads from persisted evidence.
- Real Feishu/IM credentials must never be faked as release evidence. If this smoke is absent or invalid, the release gate must restore the `feishu-im-real-credential-smoke` blocker.
- R22-12 status is a release checklist signal. The checker uses a final-review blocker only as a last safety net if concrete release evidence is complete but independent final review is not recorded.
- The checker is state-aware: blocked mode requires a blocker table and non-final manifest markers; promoted mode requires `Current status: PASS`, promoted release evidence markers, and rejects stale blocked marker ids.
