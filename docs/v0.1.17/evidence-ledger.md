## Gate Rules

- Every change must map to a Change ID, automated evidence, hand-test evidence, artifact/hash evidence when applicable, and independent review closure.
- Windows public `ready` requires Authenticode `Valid` for the setup installer and bundled executable/runtime binaries.
- macOS unsigned publication is allowed only as `ready-unsigned` with `signature: unsigned`, size, SHA256, install-smoke evidence, and visible Gatekeeper instructions.
- `pending`, `pending-signature`, `internal-handtest`, and unsigned Windows artifacts must not enter the public ready set.
